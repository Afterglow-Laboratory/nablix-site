# Product screenshots (replace these)

これらは差し替え前提のプレースホルダーです。同じファイル名で実際のスクリーンショットを
上書きし、`npm run build` すればサイトに反映されます。

| file | 掲載場所 | 推奨サイズ | 内容の目安 |
|---|---|---|---|
| hero.png | トップのメインビジュアル | 1920x1200 (16:10) | アプリ全景。数式・手書き・コードが1ページに写っている状態 |
| handwriting.png | Deep dive 1 | 1200x900 | 手書き数式 → LaTeX 変換のビフォー/アフター |
| code.png | Deep dive 2 | 1200x900 | コードブロック実行と直下の出力 |
| knowledge.png | Deep dive 3 | 1200x900 | 定義ホバーカード or 用語集 or ページマップ |
| ai-mcp.png | Deep dive 4 | 1200x900 | AIチャットパネル or MCP許可ダイアログ |

- PNG推奨（写真的な内容ならJPEGでも可、その場合はテンプレートの拡張子も変更）
- ダークテーマで撮影するとサイトの配色と馴染みます
- 幅2xで撮って縮小するとRetina相当で綺麗に出ます
