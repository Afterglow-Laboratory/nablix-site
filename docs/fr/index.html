Un carnet qui exécute

Les blocs de code ne sont pas des captures d'écran de votre travail — ils sont votre travail. Exécutez-les sur place et gardez les résultats à côté du raisonnement.

  • Plus de 17 langages : Python, JavaScript / TypeScript, Rust, C, C++, Go, R, Ruby et plus
  • Sortie en ligne juste sous le bloc — réexécutez à volonté
  • Espaces de travail par page : chaque page correspond à son propre dossier ; ouvrez-y un terminal directement
  • S'appuie sur votre chaîne d'outils locale — pas de sandbox cloud, pas d'envoi de données

Nablix n'a ni abonnement IA ni serveur intermédiaire. Branchez votre propre clé OpenAI ou Anthropic — ou reliez votre agent de codage préféré directement à vos notes via MCP.

FAQ

Vos questions, nos réponses

Nablix est-il vraiment gratuit ?

Oui — la version gratuite n'est pas un essai. Vous disposez de 20 pages, d'un dossier d'espace de travail et de presque toutes les fonctions : éditeur complet, canevas, exécution de code, maths, vue graphe, recherche, export et chat IA BYOK illimité. Vous ne payez que lorsque vous avez besoin de plus d'espace.

Quelles plateformes sont prises en charge ?

Windows 10 et 11 (64 bits) aujourd'hui. Le code est multiplateforme et une version macOS est prévue dès que la version Windows sera parfaitement stable.

Où mes données sont-elles stockées ?

Dans des dossiers ordinaires sur votre propre disque — les pages sont des fichiers que vous pouvez ouvrir, sauvegarder, synchroniser ou exporter avec l'outil de votre choix. Rien n'est envoyé chez nous : il n'existe tout simplement pas de serveur « chez nous ».

Ai-je besoin d'un abonnement IA ?

Non. Les fonctions IA sont optionnelles et en BYOK (apportez votre propre clé) : vous connectez votre clé API OpenAI ou Anthropic et ne payez votre fournisseur que ce que vous consommez. Tout le reste fonctionne sans aucune clé.

Qu'est-ce que l'intégration MCP ?

Nablix embarque un serveur MCP intégré : des outils comme Claude Code, Cursor et Windsurf peuvent lire et modifier vos notes comme contexte de premier ordre. L'accès est limité à la page et à l'espace de travail actuellement ouverts — rien d'autre n'est exposé.

Que se passe-t-il quand j'atteins la limite de 20 pages ?

Rien d'effrayant. Vos notes restent toujours consultables, modifiables et exportables — la limite empêche seulement de créer de nouvelles pages au-delà de 20. Supprimez des pages pour repasser sous la limite, ou passez à Pro.

Windows affiche « éditeur inconnu » — pourquoi ?

Les premières versions ne sont pas encore signées numériquement (un certificat de signature est prévu avant la 1.0). Chaque installateur est compilé automatiquement par GitHub Actions à partir de sources taguées, vérifiables sur la page des releases. Cliquez sur « Informations complémentaires » → « Exécuter quand même » pour continuer.
