购买与许可证

购买流程是怎样的？

结账与计费由我们的登记商户（Merchant of Record）Lemon Squeezy 负责——他们处理付款、税费与发票。几分钟内你会收到一封含许可证密钥的邮件，把密钥粘贴进 Nablix（设置 → 许可证）即可完成。

一个许可证可以在多台设备上用吗？

可以。你随时可以在应用内停用某台设备上的许可证，再在另一台设备上激活。许可证按「人」授权，而不是按「机器」。

「终身版」到底是什么意思？

一次性付款即可永久解锁全部 Pro 功能，并包含应用今后的更新。它不是订阅，也不存在任何续费。

取消 Pro 后会发生什么？

你的笔记永远不会被扣为人质。一切内容仍可查看、编辑和导出。如果超出了免费版限额，只是在回到限额以内（或再次升级）之前无法新建页面和文件夹。

价格含税吗？

Lemon Squeezy 会在结账时根据你所在国家计算并加收适用的增值税/销售税，并以登记商户身份处理全部税务文书。

退款怎么处理？

你的交易对象是作为 Merchant of Record 的 Lemon Squeezy，因此退款也由该公司依其退款政策处理。请直接向 Lemon Squeezy 提出退款申请。你所在地区法定的消费者权利不受影响。

有 Microsoft Store 版吗？

Store 版正在计划中。由于商店沙箱规则禁止启动外部进程，代码执行功能将是你在本站下载的官方版独有。在本站购买的许可证适用于官方版。

AI 需要额外付费吗？

Nablix 绝不收取 AI 费用。你接入自己的 OpenAI / Anthropic API 密钥，按用量直接付费给服务商——笔记场景通常只需几分钱。所有方案（包括免费版）的 AI 对话都不限次数。
