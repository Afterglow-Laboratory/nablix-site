Features

不再切换工具。

笔记、白板、LaTeX 编辑器、REPL——在它们之间来回切换所流失的专注力，Nablix 帮你在一页之内找回来。

所见即所得的 Markdown

斜杠命令、表格、折叠块、分栏、目录。无论编辑多么丰富，保存下来的始终是普通的 .md 文件，随时可以用其他工具打开。

直接在页面上手写

在笔记的任意位置插入画布，用笔直接书写，也可以打开全屏白板。顺滑且支持压感的墨迹。

代码就地运行

在页面内运行 Python、TypeScript 等代码块，输出结果就留在块的下方。每个页面都有专属的工作区文件夹，还能打开终端。

公式与不断成长的术语表

用 KaTeX 和自定义宏快速书写公式。定义过的术语会自动汇入术语表，在任何页面悬停即可查看定义。

看见页面之间的关联

本地运行的嵌入模型会计算页面之间的语义距离，并绘制成星座般的地图。搜索同样基于语义——完全离线。

自己的 AI 密钥，MCP 扩展

设置 OpenAI / Anthropic API 密钥即可使用聊天和行内补全。内置 MCP 服务器，Claude 等外部 AI 工具可以读写你的笔记。

FAQ

常见问题

Windows 提示「未知发布者」是怎么回事？

早期版本尚未进行代码签名（计划在 1.0 之前引入签名证书）。每个安装包都由 GitHub Actions 从打了标签的源码自动构建，所有版本均可在 releases 页面核验。点击「更多信息」→「仍要运行」即可继续。

支持哪些平台？

目前支持 Windows 10 / 11（64 位）。代码库已做跨平台设计，待 Windows 版足够稳定后将推出 macOS 版。

我的数据保存在哪里？

保存在你自己硬盘上的普通文件夹中——页面就是文件，可以用任何工具打开、备份、同步或导出。不会向我们上传任何内容，事实上根本不存在「我们的服务器」。

需要订阅 AI 服务吗？

不需要。在 Nablix 中使用 AI 的推荐方式是 MCP 集成：接入你已经在用的助手（Claude Code、Codex、Cursor、Antigravity 等），它就能直接读写你的笔记。也有内置的副驾可以填入你自己的 OpenAI 或 Anthropic API 密钥，但功能有限，现已不再推荐。Nablix 不依赖 AI：其余功能无需密钥、也无需助手即可使用。

MCP 集成是什么？

Nablix 内置 MCP 服务器，让 Claude Code、Codex、Cursor、Antigravity 等工具能把你的笔记作为一等上下文来读写。访问范围仅限你当前打开的页面及其工作区，其余内容不会暴露。 你也可以在侧边栏右键点击某个页面，把它设为不让 AI 接触。该页面及其下属页面从此无法被任何 AI 工具读取或修改，内置副驾也不例外。
