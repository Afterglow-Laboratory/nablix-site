FAQ

常见问题

Nablix 真的免费吗？

是的——免费版不是试用版。你可以使用 20 个页面、1 个工作区文件夹，以及几乎全部功能：完整编辑器、画布、代码执行、公式、图谱视图、搜索、导出，还有不限次数的 BYOK AI 对话。只有当空间不够时才需要升级。

支持哪些平台？

目前支持 Windows 10 / 11（64 位）。代码库已做跨平台设计，待 Windows 版足够稳定后将推出 macOS 版。

我的数据保存在哪里？

保存在你自己硬盘上的普通文件夹中——页面就是文件，可以用任何工具打开、备份、同步或导出。不会向我们上传任何内容，事实上根本不存在「我们的服务器」。

需要订阅 AI 服务吗？

不需要。AI 功能是可选的，并采用 BYOK（自带密钥）方式：接入你自己的 OpenAI 或 Anthropic API 密钥，按用量直接付费给服务商。没有密钥，其他功能照常使用。

MCP 集成是什么？

Nablix 内置 MCP 服务器，让 Claude Code、Cursor、Windsurf 等工具能把你的笔记作为一等上下文来读写。访问范围仅限你当前打开的页面及其工作区，其余内容不会暴露。

达到 20 页上限后会怎样？

不会发生任何可怕的事。你的笔记始终可以查看、编辑和导出——免费版的限制只是阻止创建第 21 个页面。删除部分页面回到上限以内，或升级到 Pro 即可。

Windows 提示「未知发布者」是怎么回事？

早期版本尚未进行代码签名（计划在 1.0 之前引入签名证书）。每个安装包都由 GitHub Actions 从打了标签的源码自动构建，所有版本均可在 releases 页面核验。点击「更多信息」→「仍要运行」即可继续。
