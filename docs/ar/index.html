الميزات

توقف عن التنقل بين الأدوات.

الملاحظات والسبورة ومحرر LaTeX وREPL — التركيز الذي كنت تفقده بالتنقل بينها يعود حين تتشارك صفحة واحدة.

‏Markdown تحرّره في مكانه

أوامر شرطة مائلة، جداول، كتل قابلة للطي، أعمدة، فهرس. مهما بلغ ثراء التحرير، يُحفظ الملف كـ .md عادي يمكن فتحه في أي مكان.

كتابة يدوية على الصفحة مباشرة

أدرج لوحة رسم في أي موضع من الملاحظة واكتب بقلمك — أو افتح سبورة بملء الشاشة. حبر سلس حساس للضغط.

شيفرة تعمل فعلًا

شغِّل Python وTypeScript وغيرهما داخل الصفحة وأبقِ الناتج أسفل الكتلة مباشرة. لكل صفحة مجلد عمل خاص بها مع طرفية.

رياضيات ومسرد ينمو

‏KaTeX مع وحدات ماكرو مخصصة لكتابة سريعة. المصطلحات التي تعرّفها تنضم تلقائيًا إلى مسرد وتظهر عند التحويم من أي صفحة.

انظر كيف ترتبط صفحاتك

نموذج تضمين محلي يقيس التقارب الدلالي بين صفحاتك ويرسمها ككوكبة. البحث دلالي أيضًا — ويعمل دون اتصال بالكامل.

مفاتيح الذكاء الاصطناعي الخاصة بك، موسّعة عبر MCP

أدخل مفتاح OpenAI أو Anthropic الخاص بك للدردشة والإكمال أثناء الكتابة. خادم MCP مدمج يتيح لأدوات مثل Claude قراءة ملاحظاتك وكتابتها.

رياضيات بسرعة يدك.

حين لا تجاري الكتابةُ التفكيرَ، ارسم مباشرة. تُحوَّل المعادلات اليدوية إلى KaTeX وتُنسَّق بأناقة على الصفحة.

  • لوحة داخل السطر — كتلة كتابة يدوية بين الفقرات
  • كتابة يدوية → LaTeX — يحوّل الذكاء الاصطناعي خطوطك إلى كتلة معادلة
  • ‏KaTeX في كل مكان — معادلات داخل السطر وكتل وماكرو مخصصة
  • لوحة تحرير المعادلات — حرّر المصدر وأنت ترى النتيجة
تشغيل

مختبر صغير داخل ملاحظاتك.

كتلة الشيفرة ليست لقطة شاشة للعمل — إنها العمل نفسه. جرّب وصحّح وأبقِ النتيجة إلى جوار أفكارك.

  • مشغّلات متعددة اللغات — Python وJavaScript / TypeScript وC / C++ وGo وغيرها
  • ناتج داخل الصفحة — النتيجة أسفل الكتلة، وأعد التشغيل متى شئت
  • مساحة عمل لكل صفحة — لكل صفحة مجلدها وطرفيتها
  • تشغيل محلي — جهازك وأدواتك، ولا يُرفع أي شيء
ربط

ملاحظات تتحول إلى شبكة.

التعريفات تعيش عبر الصفحات. كلما كتبت أكثر، نما مسردك — وتُظهر الخريطة كيف يرتبط كل شيء.

  • كتل التعريف — أشر إلى مصطلح من أي صفحة، وتظهر البطاقة عند التحويم
  • عرض المسرد — كل التعريفات في مكان واحد منظمة بالوسوم
  • روابط الصفحات — اربط الملاحظات مباشرة وتنقل بينها
  • خريطة الصفحات — البحث الدلالي المحلي يرسم الصفحات المتقاربة ككوكبة
ذكاء اصطناعي × MCP

الذكاء الاصطناعي تحت سيطرتك.

لا اشتراك ذكاء اصطناعي في Nablix ولا خادم وسيط. أحضر مفتاح OpenAI أو Anthropic الخاص بك، أو صِل وكيلك المعتاد عبر MCP.

  • دردشة تفهم الصفحة — حوار مبني على الملاحظة المفتوحة
  • إكمال أثناء الكتابة — اقتراحات وأنت تكتب (Pro)
  • خادم MCP مدمج — أدوات مثل Claude Code تقرأ الصفحات وتحرّرها بل وتنشئ عروض المخططات
  • أذونات صريحة — الوصول إلى المجلد وإنشاء الصفحات فقط بعد موافقتك داخل التطبيق

أسئلة وأجوبة

هل Nablix مجاني حقًا؟

نعم — الخطة المجانية ليست نسخة تجريبية. تحصل على 20 صفحة ومجلد مساحة عمل واحد وكل الميزات تقريبًا: المحرر الكامل واللوحة وتشغيل الكود والرياضيات وعرض المخطط والبحث والتصدير ومحادثة ذكاء اصطناعي بلا حدود بمفتاحك. لا تدفع إلا حين تحتاج مساحة أكبر.

ما المنصات المدعومة؟

حاليًا Windows 10 و11 (64-بت). قاعدة الكود متعددة المنصات، ونسخة macOS مخطط لها فور استقرار نسخة Windows تمامًا.

أين تُخزَّن بياناتي؟

في مجلدات عادية على قرصك الخاص — الصفحات ملفات يمكنك فتحها ونسخها احتياطيًا ومزامنتها وتصديرها بأي أداة تحب. لا يُرفع شيء إلينا؛ فلا وجود لخادم «لدينا» أصلًا.

هل أحتاج اشتراك ذكاء اصطناعي؟

لا. ميزات الذكاء الاصطناعي اختيارية وبنظام «أحضر مفتاحك»: تصل مفتاح OpenAI أو Anthropic الخاص بك وتدفع لمزوّدك حسب استخدامك فقط. كل ما عدا ذلك يعمل بلا أي مفتاح.

ما تكامل MCP؟

يضم Nablix خادم MCP مدمجًا، فتستطيع أدوات مثل Claude Code وCursor وWindsurf قراءة ملاحظاتك وتحريرها كسياق من الدرجة الأولى. الوصول مقصور على الصفحة ومساحة العمل المفتوحتين حاليًا — ولا يُكشف أي شيء آخر.

ماذا يحدث عند بلوغ حد العشرين صفحة؟

لا شيء مخيف. تبقى ملاحظاتك قابلة للعرض والتحرير والتصدير دائمًا — الحد يمنع فقط إنشاء صفحات جديدة بعد العشرين. احذف صفحات لتعود تحت الحد، أو رقِّ إلى Pro.

يقول Windows «ناشر غير معروف» — لماذا؟

الإصدارات المبكرة لم تُوقَّع رقميًا بعد (شهادة التوقيع مخطط لها قبل 1.0). يُبنى كل مثبِّت تلقائيًا عبر GitHub Actions من مصدر موسوم، ويمكن التحقق من كل إصدار في صفحة الإصدارات. اضغط «مزيد من المعلومات» ثم «التشغيل على أي حال» للمتابعة.
