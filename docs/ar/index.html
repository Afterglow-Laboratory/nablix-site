الميزات

صفحة واحدة لكل طرق تفكيرك.

كفاك تنقّلًا بين تطبيق ملاحظات وسبّورة ومحرر LaTeX وبيئة تشغيل. يطوي Nablix كل ذلك في مساحة عمل واحدة سريعة.

✍️

لوحة كتابة يدوية لا نهائية

فكِّر بالحبر على لوحات بلا حدود — كصفحات سبّورة مستقلة أو ككتل مدمجة مباشرة داخل Markdown.

⚡

كود يعمل فعلًا

شغِّل Python وTypeScript وRust وC++‎ وأكثر من 17 لغة داخل الصفحة بأسلوب Jupyter، ويظهر الناتج أسفل الكتلة مباشرة.

✨

حبر ← LaTeX، صورة ← Markdown

اكتب معادلة بخط يدك ودع الذكاء الاصطناعي يحوّلها إلى KaTeX أنيق. الصق لقطة شاشة واحصل على Markdown قابل للتحرير.

🕸

مخطط مترابط، لا كومة أوراق

روابط [[ويكي]] ثنائية الاتجاه، وتعريفات تظهر عند التمرير، وخريطة صفحات كأنها كوكبة نجوم — لتتحول ملاحظاتك المتناثرة إلى عقل ثانٍ.

🤖

ذكاؤك الاصطناعي، بمفتاحك

أحضر مفتاح OpenAI أو Anthropic الخاص بك: محادثة بسياق الصفحة، وإكمال أثناء الكتابة، وربط الوكلاء عبر MCP. مفاتيحك لا تغادر جهازك أبدًا.

🔒

محلي أولًا. حقًا.

مبني بـ Rust + Tauri: إقلاع فوري، عمل كامل دون اتصال، وصفر قياس عن بُعد. تعيش ملاحظاتك في مجلدات عادية تملكها وتستطيع تصديرها متى شئت.

ملاحظات بمستوى الرياضيات، والحبر معها

رياضيات KaTeX بماكروهات مخصصة، وكتل تعريف بتلميحات عند التمرير، وأعمدة وقوائم قابلة للطي — وحين تكون الكتابة أبطأ من الفكرة، ارسمها فحسب.

  • لوحة كتابة يدوية كصفحات كاملة أو ككتل داخل أي ملاحظة
  • ترجمة الحبر بالذكاء الاصطناعي — تتحول الكتابة اليدوية إلى Markdown أو LaTeX بلمسة واحدة
  • KaTeX في كل مكان: رياضيات داخل السطر وكتل رياضية وماكروهات قابلة لإعادة الاستخدام
  • كتل التعريف — مرِّر فوق أي مرجع لترى بطاقة تعريفه

الذكاء الاصطناعي بشروطك

لا يفرض Nablix اشتراك ذكاء اصطناعي ولا خادمًا وسيطًا. صِل مفتاح OpenAI أو Anthropic الخاص بك — أو اربط وكيل البرمجة المفضل لديك بملاحظاتك مباشرة عبر MCP.

  • محادثة ذكاء اصطناعي ترى الصفحة الحالية — بلا حدود حتى في الخطة المجانية
  • إكمال داخل السطر أثناء كتابتك (Pro)
  • خادم MCP مدمج: يستطيع Claude Code وCursor وWindsurf قراءة ملاحظاتك وتحريرها
  • نطاق مقيَّد بالتصميم — لا يرى الوكلاء سوى الصفحة ومساحة العمل المفتوحتين
بلا حساب. بلا سحابة. بلا قياس عن بُعد.

يتصل Nablix بالإنترنت في ثلاث حالات فقط: نداءات الذكاء الاصطناعي (بمفتاحك ولمزوّدك المختار)، وتفعيل الترخيص (Lemon Squeezy)، والتحقق من التحديثات (GitHub). هذه القائمة كلها — وسياسة الخصوصية قصيرة بما يكفي لتُقرأ فعلًا.

FAQ

أسئلة وأجوبة

هل Nablix مجاني حقًا؟

نعم — الخطة المجانية ليست نسخة تجريبية. تحصل على 20 صفحة ومجلد مساحة عمل واحد وكل الميزات تقريبًا: المحرر الكامل واللوحة وتشغيل الكود والرياضيات وعرض المخطط والبحث والتصدير ومحادثة ذكاء اصطناعي بلا حدود بمفتاحك. لا تدفع إلا حين تحتاج مساحة أكبر.

ما المنصات المدعومة؟

حاليًا Windows 10 و11 (64-بت). قاعدة الكود متعددة المنصات، ونسخة macOS مخطط لها فور استقرار نسخة Windows تمامًا.

أين تُخزَّن بياناتي؟

في مجلدات عادية على قرصك الخاص — الصفحات ملفات يمكنك فتحها ونسخها احتياطيًا ومزامنتها وتصديرها بأي أداة تحب. لا يُرفع شيء إلينا؛ فلا وجود لخادم «لدينا» أصلًا.

هل أحتاج اشتراك ذكاء اصطناعي؟

لا. ميزات الذكاء الاصطناعي اختيارية وبنظام «أحضر مفتاحك»: تصل مفتاح OpenAI أو Anthropic الخاص بك وتدفع لمزوّدك حسب استخدامك فقط. كل ما عدا ذلك يعمل بلا أي مفتاح.

ما تكامل MCP؟

يضم Nablix خادم MCP مدمجًا، فتستطيع أدوات مثل Claude Code وCursor وWindsurf قراءة ملاحظاتك وتحريرها كسياق من الدرجة الأولى. الوصول مقصور على الصفحة ومساحة العمل المفتوحتين حاليًا — ولا يُكشف أي شيء آخر.

ماذا يحدث عند بلوغ حد العشرين صفحة؟

لا شيء مخيف. تبقى ملاحظاتك قابلة للعرض والتحرير والتصدير دائمًا — الحد يمنع فقط إنشاء صفحات جديدة بعد العشرين. احذف صفحات لتعود تحت الحد، أو رقِّ إلى Pro.

يقول Windows «ناشر غير معروف» — لماذا؟

الإصدارات المبكرة لم تُوقَّع رقميًا بعد (شهادة التوقيع مخطط لها قبل 1.0). يُبنى كل مثبِّت تلقائيًا عبر GitHub Actions من مصدر موسوم، ويمكن التحقق من كل إصدار في صفحة الإصدارات. اضغط «مزيد من المعلومات» ثم «التشغيل على أي حال» للمتابعة.
