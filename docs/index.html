FAQ

Questions, answered

Is Nablix really free?

Yes — the Free plan is not a trial. You get 20 pages, one workspace folder, and almost every feature: the full editor, canvas, code execution, math, graph view, search, export and unlimited BYOK AI chat. You only upgrade when you need more room.

Which platforms are supported?

Windows 10 and 11 (64-bit) today. The codebase is cross-platform and a macOS build is planned once the Windows version is rock solid.

Where is my data stored?

In ordinary folders on your own disk — pages are files you can open, back up, sync or export with any tool you like. Nothing is uploaded to us. There is no 'us' server at all.

Do I need an AI subscription?

No. AI features are optional and BYOK (bring your own key): you connect your own OpenAI or Anthropic API key and pay your provider only for what you use. Everything else works without any key.

What is the MCP integration?

Nablix ships a built-in MCP server, so tools like Claude Code, Cursor and Windsurf can read and edit your notes as first-class context. Access is scoped to the page and workspace you currently have open — nothing else is exposed.

What happens when I hit the 20-page limit?

Nothing scary. Your notes always remain viewable, editable and exportable — Free limits only stop you from creating new pages beyond 20. Delete pages to get back under the limit, or upgrade to Pro.

Windows says 'unknown publisher' — why?

Early builds are not yet code-signed (a signing certificate is planned before 1.0). Every installer is built automatically from tagged source by GitHub Actions, and you can inspect each release on the releases page. Click 'More info' → 'Run anyway' to proceed.
