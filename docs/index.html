Features

Stop switching tools.

Notes, whiteboard, LaTeX editor, REPL — the focus you lost jumping between them comes back when they share one page.

Markdown you edit in place

Slash commands, tables, toggles, columns, a table of contents. However rich the editing, what is saved is a plain .md file you can open anywhere.

Handwriting, right on the page

Drop a canvas anywhere in a note and write with your pen — or open a full-page whiteboard. Smooth, pressure-aware ink.

Code that actually runs

Run Python, TypeScript and more inside the page and keep the output right below the block. Every page has its own workspace folder, terminal included.

Math, and a glossary that grows

KaTeX with custom macros for fast math. Terms you define collect into a glossary automatically and pop up on hover from any page.

See how pages relate

A local embedding model measures how close your pages are in meaning and draws them as a constellation. Search is semantic too — and fully offline.

Your own AI keys, extended by MCP

Plug in your OpenAI or Anthropic API key for chat and inline completion. A built-in MCP server lets tools like Claude read and write your notes.

Ink × Math

Math at the speed of your hand.

When typing cannot keep up with thinking, just draw. Handwritten formulas are converted to KaTeX and set beautifully on the page.

  • Inline canvas — a handwriting block between paragraphs
  • Handwriting → LaTeX — AI turns your strokes into a math block
  • KaTeX everywhere — inline math, math blocks, custom macros
  • Math editor panel — edit the source while watching it render
Run

A small laboratory inside your notes.

A code block is not a screenshot of work — it is the work. Try, fix, and keep the result next to your thinking.

  • Multi-language runners — Python, JavaScript / TypeScript, C / C++, Go and more
  • Inline output — results right under the block, re-run any time
  • Per-page workspace — each page has its own folder and terminal
  • Runs locally — your machine, your toolchain, nothing uploaded
Connect

Notes that become a network.

Definitions live across pages. The more you write, the more your glossary grows — and the map shows how everything relates.

  • Definition blocks — reference a term from any page, hover for the card
  • Glossary view — every definition in one place, organized by tags
  • Page links — link notes directly and jump between them
  • Page map — local semantic search draws related pages as a constellation
AI × MCP

AI, under your control.

Nablix has no AI subscription and no middleman server. Bring your own OpenAI or Anthropic key, or connect the agent you already use via MCP.

  • Chat that knows the page — conversation grounded in the open note
  • Inline completion — suggestions as you type (Pro)
  • Built-in MCP server — external tools like Claude Code can read, edit, even create graph views
  • Explicit permissions — folder access and page creation only after you approve an in-app dialog
No account. No cloud. No telemetry.

Nablix talks to the internet in exactly three cases: your AI calls (your key, your provider), license activation (Lemon Squeezy) and update checks (GitHub). That is the entire list — and the privacy policy is short enough to actually read.

FAQ

Questions, answered

Is Nablix really free?

Yes — the Free plan is not a trial. You get 20 pages, one workspace folder, and almost every feature: the full editor, canvas, code execution, math, graph view, search, export and unlimited BYOK AI chat. You only upgrade when you need more room.

Which platforms are supported?

Windows 10 and 11 (64-bit) today. The codebase is cross-platform and a macOS build is planned once the Windows version is rock solid.

Where is my data stored?

In ordinary folders on your own disk — pages are files you can open, back up, sync or export with any tool you like. Nothing is uploaded to us. There is no 'us' server at all.

Do I need an AI subscription?

No. AI features are optional and BYOK (bring your own key): you connect your own OpenAI or Anthropic API key and pay your provider only for what you use. Everything else works without any key.

What is the MCP integration?

Nablix ships a built-in MCP server, so tools like Claude Code, Cursor and Windsurf can read and edit your notes as first-class context. Access is scoped to the page and workspace you currently have open — nothing else is exposed.

What happens when I hit the 20-page limit?

Nothing scary. Your notes always remain viewable, editable and exportable — Free limits only stop you from creating new pages beyond 20. Delete pages to get back under the limit, or upgrade to Pro.

Windows says 'unknown publisher' — why?

Early builds are not yet code-signed (a signing certificate is planned before 1.0). Every installer is built automatically from tagged source by GitHub Actions, and you can inspect each release on the releases page. Click 'More info' → 'Run anyway' to proceed.
