Features

एक पेज। सोचने का हर तरीक़ा।

नोट ऐप, व्हाइटबोर्ड, LaTeX एडिटर और REPL के बीच भागना बंद करें। Nablix इन सबको एक तेज़ वर्कस्पेस में समेट देता है।

✍️

अनंत हस्तलेखन कैनवास

असीम कैनवास पर क़लम से सोचें — स्वतंत्र व्हाइटबोर्ड पेज के रूप में, या सीधे आपके Markdown में जड़े ब्लॉक के रूप में।

⚡

कोड जो सचमुच चलता है

Python, TypeScript, Rust, C++ समेत 17+ भाषाएँ Jupyter-शैली में वहीं चलाएँ। आउटपुट ब्लॉक के ठीक नीचे आता है।

✨

इंक → LaTeX, इमेज → Markdown

समीकरण हाथ से लिखें और AI उसे साफ़-सुथरे KaTeX में बदल देगा। स्क्रीनशॉट चिपकाएँ, संपादन-योग्य Markdown पाएँ।

🕸

ढेर नहीं, ग्राफ़

दोतरफ़ा [[विकि लिंक]], होवर पर खुलती परिभाषाएँ और तारामंडल-सा Page Map बिखरे नोट्स को दूसरा दिमाग़ बना देते हैं।

🤖

आपकी AI, आपकी कुंजी

अपनी OpenAI या Anthropic कुंजी जोड़ें। पेज के संदर्भ में चैट करें, टाइप करते हुए पूर्णता पाएँ, MCP से एजेंट जोड़ें। कुंजियाँ कभी आपकी मशीन से बाहर नहीं जातीं।

🔒

Local-first। सच में।

Rust + Tauri से निर्मित: तुरंत स्टार्ट, पूरी तरह ऑफ़लाइन, शून्य टेलीमेट्री। नोट्स आपके अपने सामान्य फ़ोल्डरों में रहते हैं और कभी भी निर्यात किए जा सकते हैं।

गणित-स्तर के नोट्स, इंक समेत

कस्टम मैक्रो वाला KaTeX गणित, होवर टूलटिप वाले परिभाषा ब्लॉक, कॉलम और टॉगल — और जब टाइपिंग विचार से धीमी पड़े, तो बस बना डालिए।

  • हस्तलेखन कैनवास — पूरे पेज के रूप में या किसी भी नोट के भीतर इनलाइन ब्लॉक के रूप में
  • AI इंक अनुवाद — हस्तलेखन एक टैप में Markdown या LaTeX बन जाता है
  • हर जगह KaTeX: इनलाइन गणित, गणित ब्लॉक और पुन: प्रयोज्य मैक्रो
  • परिभाषा ब्लॉक — किसी भी संदर्भ पर होवर करें और उसका परिभाषा कार्ड देखें

नोटबुक जो निष्पादित करती है

कोड ब्लॉक आपके काम के स्क्रीनशॉट नहीं हैं — वे ख़ुद आपका काम हैं। उन्हें वहीं चलाएँ और नतीजों को तर्क के बगल में रखें।

  • 17+ भाषाएँ: Python, JavaScript / TypeScript, Rust, C, C++, Go, R, Ruby और भी
  • इनलाइन आउटपुट ब्लॉक के ठीक नीचे — जब चाहें फिर चलाएँ
  • प्रति-पेज वर्कस्पेस: हर पेज का अपना फ़ोल्डर; वहीं टर्मिनल खोलें
  • आपकी स्थानीय टूलचेन पर चलता है — न क्लाउड सैंडबॉक्स, न अपलोड
# prototype inside the note — no editor switch
import numpy as np

w, v = np.linalg.eig(A)
print("eigenvalues:", w.round(3))

FAQ

सवाल, जवाब सहित

क्या Nablix सच में मुफ़्त है?

हाँ — Free प्लान कोई ट्रायल नहीं है। आपको 20 पेज, एक वर्कस्पेस फ़ोल्डर और लगभग हर सुविधा मिलती है: पूरा एडिटर, कैनवास, कोड निष्पादन, गणित, ग्राफ़ व्यू, खोज, निर्यात और असीमित BYOK AI चैट। अपग्रेड तभी करें जब ज़्यादा जगह चाहिए।

कौन से प्लेटफ़ॉर्म समर्थित हैं?

अभी Windows 10 और 11 (64-बिट)। कोडबेस क्रॉस-प्लेटफ़ॉर्म है और Windows संस्करण के पूरी तरह स्थिर होते ही macOS बिल्ड की योजना है।

मेरा डेटा कहाँ संग्रहीत होता है?

आपकी अपनी डिस्क के सामान्य फ़ोल्डरों में — पेज ऐसी फ़ाइलें हैं जिन्हें आप किसी भी टूल से खोल, बैकअप, सिंक या निर्यात कर सकते हैं। हमें कुछ भी अपलोड नहीं होता। दरअसल, हमारा कोई सर्वर है ही नहीं।

क्या मुझे AI सब्सक्रिप्शन चाहिए?

नहीं। AI सुविधाएँ वैकल्पिक और BYOK (अपनी कुंजी लाएँ) हैं: आप अपनी OpenAI या Anthropic API कुंजी जोड़ते हैं और जितना उपयोग करें उतना सीधे प्रदाता को देते हैं। बाक़ी सब कुछ बिना किसी कुंजी के चलता है।

MCP एकीकरण क्या है?

Nablix में MCP सर्वर अंतर्निर्मित है, जिससे Claude Code, Cursor और Windsurf जैसे टूल आपके नोट्स को प्रथम-श्रेणी संदर्भ की तरह पढ़-लिख सकते हैं। पहुँच केवल उस पेज और वर्कस्पेस तक सीमित है जो आपने खोला है — बाक़ी कुछ भी उजागर नहीं होता।

20-पेज की सीमा पर पहुँचने पर क्या होता है?

कुछ भी डरावना नहीं। आपके नोट्स हमेशा देखे, संपादित और निर्यात किए जा सकते हैं — सीमा केवल 20 से आगे नए पेज बनाने से रोकती है। पेज हटाकर सीमा के भीतर लौटें, या Pro लें।

Windows «अज्ञात प्रकाशक» कहता है — क्यों?

शुरुआती बिल्ड अभी कोड-साइन नहीं हैं (1.0 से पहले साइनिंग प्रमाणपत्र की योजना है)। हर इंस्टॉलर GitHub Actions द्वारा टैग किए स्रोत से स्वतः बनता है और हर रिलीज़ releases पेज पर जाँची जा सकती है। आगे बढ़ने के लिए «More info» → «Run anyway» क्लिक करें।
