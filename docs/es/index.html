FAQ

Preguntas, respondidas

¿Nablix es gratis de verdad?

Sí — el plan Gratis no es una prueba. Tienes 20 páginas, una carpeta de espacio de trabajo y casi todas las funciones: editor completo, lienzo, ejecución de código, matemáticas, vista de grafo, búsqueda, exportación y chat IA BYOK ilimitado. Solo pagas cuando necesitas más espacio.

¿Qué plataformas son compatibles?

Hoy, Windows 10 y 11 (64 bits). El código es multiplataforma y hay una versión para macOS planificada en cuanto la de Windows sea totalmente estable.

¿Dónde se guardan mis datos?

En carpetas normales de tu propio disco: las páginas son archivos que puedes abrir, respaldar, sincronizar o exportar con la herramienta que prefieras. No se sube nada a nuestros servidores; de hecho, no existe ningún servidor nuestro.

¿Necesito una suscripción de IA?

No. Las funciones de IA son opcionales y BYOK (trae tu propia clave): conectas tu clave API de OpenAI o Anthropic y pagas a tu proveedor solo por lo que uses. Todo lo demás funciona sin ninguna clave.

¿Qué es la integración MCP?

Nablix incluye un servidor MCP integrado, así que herramientas como Claude Code, Cursor y Windsurf pueden leer y editar tus notas como contexto de primera clase. El acceso se limita a la página y al espacio de trabajo que tengas abiertos — nada más queda expuesto.

¿Qué pasa cuando llego al límite de 20 páginas?

Nada aterrador. Tus notas siempre se pueden ver, editar y exportar — el límite solo impide crear páginas nuevas más allá de 20. Borra páginas para volver bajo el límite, o pásate a Pro.

Windows dice «editor desconocido», ¿por qué?

Las primeras versiones aún no están firmadas digitalmente (hay un certificado de firma previsto antes de la 1.0). Cada instalador lo compila automáticamente GitHub Actions desde código etiquetado, verificable en la página de releases. Haz clic en «Más información» → «Ejecutar de todas formas» para continuar.
