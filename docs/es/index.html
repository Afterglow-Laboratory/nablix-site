Funciones

Deja de cambiar de herramienta.

Notas, pizarra, editor LaTeX, REPL: la concentración que perdías saltando entre ellos vuelve cuando comparten una misma página.

Markdown que editas en el sitio

Comandos slash, tablas, bloques plegables, columnas, índice. Por rica que sea la edición, lo que se guarda es un simple archivo .md que puedes abrir en cualquier parte.

Escritura a mano, directamente en la página

Inserta un lienzo donde quieras y escribe con tu lápiz, o abre una pizarra a pantalla completa. Tinta fluida y sensible a la presión.

Código que realmente se ejecuta

Ejecuta Python, TypeScript y más dentro de la página y conserva la salida justo debajo del bloque. Cada página tiene su propia carpeta de trabajo, terminal incluida.

Matemáticas y un glosario que crece

KaTeX con macros personalizadas para escribir rápido. Los términos que defines se reúnen automáticamente en un glosario y aparecen al pasar el cursor desde cualquier página.

Ve cómo se relacionan tus páginas

Un modelo de embeddings local mide la cercanía semántica de tus páginas y las dibuja como una constelación. La búsqueda también es semántica, y totalmente offline.

Tus propias claves de IA, ampliadas con MCP

Conecta tu clave de OpenAI o Anthropic para chat y autocompletado. Un servidor MCP integrado permite que herramientas como Claude lean y escriban tus notas.

Tinta × Mates

Matemáticas a la velocidad de tu mano.

Cuando teclear no alcanza al pensamiento, dibuja. Las fórmulas manuscritas se convierten a KaTeX y quedan compuestas con elegancia en la página.

  • Lienzo en línea — un bloque manuscrito entre párrafos
  • Manuscrito → LaTeX — la IA convierte tus trazos en un bloque de fórmula
  • KaTeX en todas partes — fórmulas en línea, bloques, macros personalizadas
  • Panel de edición — edita la fuente mientras ves el resultado
Ejecutar

Un pequeño laboratorio dentro de tus notas.

Un bloque de código no es la captura de un trabajo: es el trabajo. Prueba, corrige y guarda el resultado junto a tu pensamiento.

  • Ejecutores multilenguaje — Python, JavaScript / TypeScript, C / C++, Go y más
  • Salida en línea — el resultado bajo el bloque, re-ejecutable cuando quieras
  • Carpeta por página — cada página tiene su propio espacio de trabajo y terminal
  • Ejecución local — tu máquina, tus herramientas, nada se sube
Conectar

Notas que se vuelven una red.

Las definiciones viven entre páginas. Cuanto más escribes, más crece tu glosario, y el mapa muestra cómo se relaciona todo.

  • Bloques de definición — referencia un término desde cualquier página, tarjeta al pasar el cursor
  • Vista de glosario — todas las definiciones en un lugar, organizadas por etiquetas
  • Enlaces entre páginas — enlaza notas directamente y salta entre ellas
  • Mapa de páginas — la búsqueda semántica local dibuja las páginas afines como constelación
IA × MCP

La IA, bajo tu control.

Nablix no tiene suscripción de IA ni servidor intermediario. Trae tu propia clave de OpenAI o Anthropic, o conecta tu agente habitual vía MCP.

  • Chat que entiende la página — conversación basada en la nota abierta
  • Autocompletado en línea — sugerencias mientras escribes (Pro)
  • Servidor MCP integrado — herramientas como Claude Code pueden leer, editar e incluso crear vistas de grafo
  • Permisos explícitos — acceso a carpetas y creación de páginas solo tras tu aprobación

FAQ

Preguntas, respondidas

Windows dice «editor desconocido», ¿por qué?

Las primeras versiones aún no están firmadas digitalmente (hay un certificado de firma previsto antes de la 1.0). Cada instalador lo compila automáticamente GitHub Actions desde código etiquetado, verificable en la página de releases. Haz clic en «Más información» → «Ejecutar de todas formas» para continuar.

¿Qué plataformas son compatibles?

Hoy, Windows 10 y 11 (64 bits). El código es multiplataforma y hay una versión para macOS planificada en cuanto la de Windows sea totalmente estable.

¿Dónde se guardan mis datos?

En carpetas normales de tu propio disco: las páginas son archivos que puedes abrir, respaldar, sincronizar o exportar con la herramienta que prefieras. No se sube nada a nuestros servidores; de hecho, no existe ningún servidor nuestro.

¿Necesito una suscripción de IA?

No. La forma recomendada de usar IA con Nablix es la integración MCP: conecta un asistente que ya tengas —Claude Code, Codex, Cursor, Antigravity— y trabajará directamente sobre tus notas. También hay un copiloto integrado que acepta tu propia clave API de OpenAI o Anthropic, pero es mucho más limitado y ya no es la vía recomendada. Nada en Nablix depende de la IA: todo lo demás funciona sin clave y sin asistente.

¿Qué es la integración MCP?

Nablix incluye un servidor MCP integrado, así que herramientas como Claude Code, Codex, Cursor y Antigravity pueden leer y editar tus notas como contexto de primera clase. El acceso se limita a la página y al espacio de trabajo que tengas abiertos — nada más queda expuesto. También puedes marcar una página como vedada a la IA, con el botón derecho en la barra lateral. Esa página y todo lo que cuelga de ella dejan de poder ser leídas o modificadas por cualquier herramienta de IA, incluido el copiloto integrado.
