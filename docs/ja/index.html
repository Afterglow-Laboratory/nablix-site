Features

1ページに、思考のすべてを。

ノートアプリとホワイトボードとLaTeXエディタとREPLを行き来するのは、もう終わり。Nablixはそれを1つの高速なワークスペースに畳み込みます。

✍️

無限の手書きキャンバス

境界のないキャンバスに、ペンで直接思考を。独立したホワイトボードページとしても、Markdown内への埋め込みブロックとしても使えます。

⚡

コードが「動く」ノート

Python、TypeScript、Rust、C++など17以上の言語をJupyterのようにその場で実行。出力はブロックのすぐ下に表示されます。

✨

手書き→LaTeX、画像→Markdown

数式を手で書けば、AIが綺麗なKaTeXに変換。スクリーンショットを貼れば、編集可能なMarkdownが返ってきます。

🕸

積み上げず、つなげる

双方向の[[Wikiリンク]]、ホバーで開く定義ブロック、星座のようなページマップ。散らばったノートが第二の脳に変わります。

🤖

AIは自分のキーで

OpenAIまたはAnthropicのAPIキーを接続。ページを文脈にしたチャット、入力中の補完、MCP経由のエージェント連携。キーがあなたのPCから出ることはありません。

🔒

本物のローカルファースト

Rust + Tauri製。一瞬で起動し、完全オフラインで動き、テレメトリはゼロ。ノートはあなたが所有する普通のフォルダに保存され、いつでもエクスポートできます。

書く · 描く · 解く

数式に強いノートに、インクを添えて

カスタムマクロ対応のKaTeX数式、ホバーで定義が浮かぶ定義ブロック、段組みやトグル。そして、タイピングが思考に追いつかないときは、そのまま描けばいい。

  • 手書きキャンバス：フルページでも、ノート内のインラインブロックでも
  • AIインク変換 — 手書きがワンタップでMarkdownやLaTeXに
  • KaTeXが全域で使える：インライン数式、数式ブロック、再利用できるマクロ
  • 定義ブロック — 参照にホバーすると定義カードが浮かび上がる

FAQ

よくある質問

Nablixは本当に無料ですか？

はい。Freeプランは体験版ではありません。20ページ・1ワークスペースの範囲で、エディタ、キャンバス、コード実行、数式、グラフビュー、検索、エクスポート、そして回数無制限のAIチャット（BYOK）まで、ほぼすべての機能が使えます。手狭になったときだけアップグレードしてください。

対応プラットフォームは？

現在はWindows 10 / 11（64bit）です。コードベースはクロスプラットフォーム対応済みで、Windows版が十分に安定したらmacOS版を予定しています。

データはどこに保存されますか？

あなたのPCの普通のフォルダの中です。ページはただのファイルなので、好きなツールで開く・バックアップする・同期する・書き出すことができます。開発者のサーバーには何もアップロードされません。そもそもサーバーが存在しません。

AIのサブスク契約が必要ですか？

いいえ。AI機能はオプションかつBYOK（自分のキーを持ち込む）方式です。OpenAIまたはAnthropicのAPIキーを接続し、使った分だけプロバイダに直接支払います。キーがなくても他の機能はすべて動きます。

MCP連携とは何ですか？

NablixはMCPサーバーを内蔵しており、Claude Code、Cursor、WindsurfのようなAIツールがあなたのノートを直接読み書きできます。アクセスできるのは現在開いているページとそのワークスペースだけ。それ以外は公開されません。

20ページの上限に達したらどうなりますか？

怖いことは何も起きません。既存のノートの閲覧・編集・エクスポートは常に可能です。Freeの制限は「20ページを超える新規作成」を止めるだけ。ページを削除して上限内に戻るか、Proにアップグレードしてください。

Windowsに「発行元不明」と警告されます

初期ビルドにはまだコード署名がありません（1.0までに署名証明書を導入予定です）。インストーラーはGitHub Actionsがタグ付きソースから自動ビルドしており、すべてのリリースはreleasesページで検証できます。「詳細情報」→「実行」で続行できます。
